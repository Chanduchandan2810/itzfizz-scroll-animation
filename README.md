# Itzfizz Scroll-Driven Hero Animation

A high-performance, scroll-driven interactive hero section built for the Itzfizz Web Development Internship assignment. The project maps native scroll progress directly to complex staggered GSAP timelines, creating an immersive, fluid visual narrative.

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger

## Features

- Scroll-linked hero animation
- Interactive crowd animation
- Scroll-driven typography
- Celebration state
- Celebrate / Reset interaction
- Responsive desktop/tablet/mobile layout
- Transform-based smooth animation

## Run Locally

```bash
npm install
npm run dev
```
